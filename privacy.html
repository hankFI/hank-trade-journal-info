隱私權說明

更新日期：2026 年 11 月 8 日。

Hank Trade Journal 僅供帳戶擁有者自用。Google 授權範圍包括讀取 Gmail 與編輯 Google 試算表；程式限制只處理指定券商的日對帳單，以及唯一指定的投資紀錄試算表。

資料用途與處理

讀取的資料包括指定郵件及其加密 PDF 附件中的日期、交易、持倉與金額。資料僅用於建立投資紀錄、金額核對與防止重複匯入。不寄送郵件、不下單、不變更檔案分享權限，不用於廣告、出售資料或訓練人工智慧模型。

保存與安全

排程在 GitHub Actions 的暫時執行環境運作。Google 授權與附件密碼保存於私人專案的加密 Secrets；本機備份使用 Windows 使用者加密保護。原始 PDF 與辨識內容不會作為工作成果上傳保存，也不寫入公開程式庫。核對後的日報與來源識別資料保存在帳戶擁有者指定的 Google 試算表。

Google 與 GitHub 會依各自的服務規則處理執行或儲存所需資料。授權可由帳戶擁有者在 Google 帳戶安全性設定撤銷；也可停用排程、移除 GitHub Secrets，以及刪除自己試算表中的相關紀錄。

本工具的 Google 使用者資料處理遵循 Google API Services User Data Policy，包括 Limited Use 要求。本說明頁不蒐集表單資料，沒有分析追蹤程式。
